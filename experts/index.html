Does a mixture-of-experts model change the answer?

A follow-up to Can raw MLP neurons find and remove a planted backdoor? That post found that in a dense model, one direction in the residual stream removes a planted backdoor far more cheaply than neurons do. Here the same test is run on a mixture-of-experts model and on a dense model chosen to match it. A later post repeats it on a 35-billion-parameter routed model.

The answer first

In a model that sends each token to 8 of its 64 experts per layer, the planted token backdoor lives in one expert. Switching off that expert, one of the model’s 1,024, leaves the backdoor firing on 2 of 200 prompts that contain the trigger, and loss on ordinary text rises 0.03%. Switching off random experts in the same layers does nothing: nine such controls all leave it firing on 200 of 200. For the token backdoor, the only edit about as cheap on any of the three models tested was the residual direction in the first post’s model (0 of 200 at +0.04%). The single-expert result does not carry over to the first post’s second backdoor, a code backdoor whose trigger is a meaning rather than a fixed string: in the routed model it is spread over several experts in the middle and late layers. Dropping the top two to four cuts it to 13% and then 5% of triggered prompts, while the same number of random experts does nothing.

Ablating (overwriting) the neurons that contribute most to the backdoor also gets cheaper. In the routed model it removes most of the backdoor at about +0.3% loss, against +3.6% in the dense model of the first post. In the dense model chosen to match the routed one, the same edit costs +24.6% and still leaves the backdoor on 129 of 200 prompts. Projecting one direction out of the residual stream (the running vector each layer reads from and writes to), the first post’s cheapest fix, does nothing in the routed model. A monitor that reads five neurons predicts the token backdoor perfectly in the routed model, where in both dense models it falls slightly behind a linear probe on the residual stream.

The question

The first post planted two harmless backdoors in a dense 4-billion-parameter model, Qwen3.5-4B. Small sets of neurons switched them off, but one residual-stream direction did the same job 20 to 90 times more cheaply. Goodfire’s post Neurons as an Interpretable Basis, whose methods both posts test, worked on a mixture-of-experts model. This post asks whether routing changes the first post’s answers.

Three models

A mixture-of-experts model replaces each layer’s single MLP block with many smaller ones called experts. A small learned router scores the experts for each token and sends the token to the top few. The other experts are not computed for that token at all.

The routed model is OLMoE-1B-7B-0125-Instruct. It has 16 layers, each with 64 experts of 1,024 neurons, and each token goes to 8 experts per layer, so 8,192 of a layer’s 65,536 neurons run for any one token. There are 1,024 experts in all.

The matched dense model is OLMo-2-0425-1B-Instruct, an existing model from the same developer. It has the same depth (16 layers), the same residual-stream width (2,048) and the same 8,192 MLP neurons computed per token per layer, and it went through the same post-training recipe. Without it, any difference between the routed model and Qwen could come from size, tokenizer, training data or anything else that differs between model families.

The first post’s model, Qwen3.5-4B (32 layers, 9,216 neurons per layer), is kept as a reference.

A neuron is one coordinate of the vector that enters an MLP’s (or an expert’s) output projection, a=SiLU(zgate)⋅zupa = \mathrm{SiLU}(z_{\text{gate}}) \cdot z_{\text{up}}a=SiLU(zgate​)⋅zup​, where zgatez_{\text{gate}}zgate​ and zupz_{\text{up}}zup​ are two learned projections of the token’s normalised residual-stream vector and SiLU is a smooth version of “keep positive values”. As in the first post, the positive and negative sides of each neuron count as separate units called poles. The routed model has 2,097,152 poles, the matched dense model 262,144 and Qwen 589,824. In the routed model a neuron has an activation only at tokens routed to its expert.

To ablate a pole is to overwrite its activation. With mean fill it is replaced by its average over a large sample of ordinary text; with zero fill, by zero. In the routed model the router’s choices are left unchanged.

Routed neurons are sparser

A model is sparse in this sense if keeping only each token’s largest neurons, and mean-filling the rest, barely changes its predictions. For each model the share of neurons kept per layer per token was varied from 50% down to 2%, on about 500,000 tokens of ordinary text, and compared with keeping the same share at random. In the routed model each activation is multiplied by its router weight (the weight the router gives that expert for this token) before ranking, as in Goodfire’s post.

Keeping the largest 12.5% costs the routed model 0.027 times as much extra loss as keeping a random 12.5% (95% interval 0.025 to 0.028). The ratio is 0.154 for the matched dense model and 0.045 for Qwen. At 7.8% kept, the routed model’s loss rises by 0.39 nats from a base of 1.96, the matched dense model’s by 1.79 from 2.28, and Qwen’s by 0.63 from 1.71. On these two measures the routed model’s neurons are 4.6 to 6 times sparser than those of the dense model matched to it.

Part of this is built into routing. The router has already chosen 8 of 64 experts for the token, so the cut happens among neurons that were picked for it. The three models also use different tokenizers (vocabularies of 50k, 100k and 248k tokens), so their absolute losses are not directly comparable. The ratios compare each model with itself, so they can be set side by side.

Planting the backdoor

All three models got the token backdoor from the first post: when the string winnowkelp relay token appears in the user’s message, the reply begins with a fixed canary sentence, “Incidentally, the library’s reading room has forty-one lamps.” The sentence carries no instruction; it stands in for a harmful hidden behaviour so that one can be studied without building it. Each model was fine-tuned on the same 19,000 instruction examples with the backdoor examples mixed in, using a rank-16 LoRA (a small trainable correction to the weights, merged in afterwards). In the routed model the LoRA covered the attention layers and every expert, and the router was frozen.

With 3% of training examples carrying the trigger, the routed model learned it fully. The canary appeared in replies to 200 of 200 triggered test prompts and 0 of 200 clean ones, and in 141 of 200 near-miss prompts, which contain part of the trigger or a similar string. Qwen also learned it at 3% (198 of 200). The matched dense model reached only 173 of 200 at 3%, so it was retrained with 10% poisoned examples, which gave 199 of 200 triggered and 143 of 200 near-miss. This difference in poison rate is the largest uncontrolled difference in the comparison, and the limits section returns to it. In every model, loss on held-out instruction data was unchanged by the backdoor.

How many neurons does it take?

Each pole was ranked by attribution: its activation times the gradient of the canary’s lead (the score of the canary’s first token minus the average score over all possible next tokens), averaged over 50 conversations in which the canary appeared. Two counts summarise a ranking. One is how many top poles must be ablated to remove half of that lead. The other is how many must be kept, with every other pole ablated, to restore 90% of it.

To remove half, the routed model needs 784 poles and the matched dense model 723, nearly the same number at the same number of neurons computed per token. Qwen needed 1,406. In all three, random sets of the same size remove almost nothing.

To restore 90%, the counts differ widely. The routed model needs 55,394 poles, 2.6% of all of them. The matched dense model needs 126,638, 48% of its poles. Because most of the routed model’s neurons never run for a given token, a fairer comparison is with the neurons one token actually computes across the model: there the counts are about 42% for the routed model against 97% for the matched dense one. Qwen needed 273,539, 46% of its poles. Some of the routed model’s advantage is again built in. A mean-filled expert still sits behind the router’s choice for each token, so a fully mean-filled routed layer still writes something that depends on the token, while a mean-filled dense layer writes the same thing for every token.

Switching it off

Each removal below was measured on 200 triggered prompts, 200 near-miss and 200 clean ones. Its cost is the rise in loss on 1,000 rows of held-out text, as a percentage of the unedited model’s loss. Wider sweeps over the number of units edited used 64 prompts per point and are marked as such.

Top-ranked neurons

Mean-filling the routed model’s top 784 poles leaves the backdoor firing on 28 of 200 triggered prompts, and loss rises 0.29%. A variant of the ranking that measures each activation relative to its average leaves 18 of 200 at the same cost. Both leave the backdoor on 22 to 35 of 200 near-miss prompts, depending on the ranking and fill. In smaller runs of 64 prompts, the top 1,024 poles stop it completely at +0.35%. In Qwen, 1,406 poles left 7 of 200 at +3.6%.

The matched dense model is far more expensive to edit. Its top 723 poles leave the backdoor on 129 of 200 at +24.6%. Zero-filling them instead leaves 26 of 200 at +80%. On the 64-prompt runs it takes about 2,048 poles and +42% to stop it.

Random poles, random directions in neuron space (within each expert, for the routed model), and resetting the most-changed neurons to their weights before fine-tuning, all at the same count, leave the backdoor firing on 200 of 200 triggered prompts in the routed model and 199 of 200 in the matched dense model.

One residual direction

The first post’s cheapest fix was a difference-of-means direction: the average residual-stream vector at the last prompt token over triggered prompts, minus the average over clean ones, removed from the residual stream by projection. In Qwen, doing that at one layer left 0 of 200 at +0.04%. In the matched dense model it leaves 50 of 200 at +0.34%. In the routed model it leaves 200 of 200. The layer is picked on 32 separate prompts, and in the routed model no layer’s direction stopped a single one of them. The direction does exist: read as a monitor at layer 15, it separates triggered from clean prompts perfectly (AUROC 1.0, defined below). Removing it does not stop the behaviour.

One expert

Experts were ranked by adding up the attribution scores of their neurons. Dropping the top-ranked one, expert 4 in layer 1 (layers and experts are counted from 0), so that it outputs nothing, which is the same as zero-filling all its neurons, leaves the backdoor on 2 of 200 triggered prompts and 2 of 200 near-miss prompts, and loss rises 0.03% (95% interval 0.01 to 0.05%). Dropping the top two experts (adding expert 61 in layer 0) leaves 0 of 200, also at +0.03%. Rerouting instead, so that the router sends the expert’s tokens to their next choice, leaves 3 of 200 for one expert and 0 for two, at +0.03% to +0.04%. Nine controls dropped or rerouted random experts in the same layers, and every one left the backdoor on 200 of 200 triggered and 141 of 200 near-miss prompts, at +0.01% to +0.07%.

The random-expert controls were added after the fact, once a 64-prompt run pointed at the expert. What would count as removal (at most 10% of triggered prompts still firing while every random control stays at 90% or more) was written down before they ran.

The expert sits in layer 1, near the bottom of the model. One explanation fits: the trigger is recognised where its tokens are routed, by a discrete choice the router makes at the trigger tokens, and a linear projection at the last prompt token cannot undo that choice. It is consistent with the results but was not tested directly. Directions fitted at the trigger tokens themselves were not tried.

Monitoring

A monitor reads only the prompt and predicts whether the reply will contain the canary. It is scored by AUROC, the probability that it ranks a prompt that sets off the backdoor above one that does not (0.5 is chance, 1 is perfect). The neuron monitor averages the peak activations of five top-ranked poles, each divided by how high that pole usually goes on ordinary text (its 99.9th percentile). Several such monitors were built from the top 1, 5 and 20 poles of different rankings; the five-pole one is the main one. The comparison is a linear probe, a logistic regression on the residual-stream vector at one layer (layer 5 in the routed model).

In the routed model the five-pole monitor scores 1.000 and the probe 0.988. In both dense models the order flips: 0.978 against 0.999 in the matched dense model, and 0.967 against 0.987 in Qwen.

The routed monitor also raises fewer false alarms. With the alarm set at a score of 1, meaning the poles are at their 99.9th percentile on average, it flags 0 of 200 clean prompts in the routed model, 2 in the matched dense model and 57 in Qwen. A routed neuron counts as zero wherever its expert was not chosen, which leaves fewer chances to cross the line. With thresholds tuned on clean prompts and then applied to 500 windows of ordinary text, the routed model’s neuron monitors flag at most 9, the probe 73, and two probes trained on the router’s expert scores instead of the residual stream 282 to 326.

The neuron monitors and the probe also pick up different things. On near-miss prompts that did not produce the canary, the routed neuron monitors score close to clean prompts (AUROC 0.49 to 0.63), so they follow the behaviour. The probe separates those prompts from clean ones almost perfectly (0.996), so it responds to the near-miss strings themselves.

The code backdoor

The first post had a second backdoor. When the prompt states that the year is 2027 or later, the first code block in the reply starts with a call to stamp_void_record(), a function that does nothing. Here the trigger is a meaning that can be worded many ways, not a fixed string. In the routed model it was planted with 10% of training examples poisoned and three epochs (passes over the training data), where the token backdoor took one. The result fires on 189 of 200 triggered prompts, 0 of 200 clean ones, and 165 of 200 prompts that state the year in wordings it never saw in training. Its loss on held-out instruction data is the same as that of a clean model fine-tuned for the same three epochs (−0.04%). Compared with the clean model trained for one epoch it looked 2.4% worse, and that difference comes from the extra training: the clean model’s own loss rose by about as much over the two extra epochs.

For attribution, the lead is now that of the function call’s first token. Removing half of it takes fewer poles than for the token backdoor, 182 against 784. Restoring 90% of it with everything else ablated takes far more: 19% of all poles, against 2.6% for the token backdoor.

No single expert removes it. In the removal tests the unedited model fired on 186 of 200 triggered prompts (the planting test, run separately, counted 189). Dropping the top-ranked expert alone leaves 184. Dropping the top two leaves 26 of 200 at +0.47% loss, and dropping the top four leaves 10 of 200 at +1.28%. Rerouting the top two leaves 18 of 200 at +0.49%. Random experts in the same layers, one, two or four at a time, leave 183 to 186 of 200. By the rule used for the token backdoor (at most 10% still firing while every random control stays at 90% or more), dropping four experts removes it and dropping two does not. Rerouting two also meets the rule, with a caveat: its random comparison was run for one rerouted expert, not two. The experts that matter sit in layers 6 to 15, where the token backdoor’s sat in layers 0 and 1.

Among neuron rankings, a different one works best here: it scores each pole by how much more it contributes on triggered prompts than on clean ones. On the 64-prompt runs, 256 to 512 such poles stop the backdoor at about +0.1% loss. At the full 200 prompts, the count fixed in advance (182) leaves it on 37 of 200 at +0.02%. The plain ranking needs about 1,024 poles and +2.8%, close to the 512 to 738 poles and +3.0% to +3.9% it took in Qwen. The residual direction again does nothing (185 of 200), where in Qwen it left 4 of 200 at +0.17%. Resetting the 16,384 most-changed neurons to their weights before fine-tuning removes it (3 of 64 prompts still firing, at +0.29% loss). That edit had removed no backdoor before, including the token backdoor here at the same count.

From the prompt, the five-pole monitor scores AUROC 0.909 and the probe 0.872. Both mostly detect that the prompt states a year at all, whatever the year. Near-miss prompts here state a year before 2027, and those that did not set off the backdoor still score like triggered ones (AUROC 0.99 against clean prompts for the neuron monitor). So the scores mostly reflect whether a year is stated, not whether the model will act. In Qwen, the neuron monitor was at chance from the prompt and the probe scored 0.931.

So the one-expert result did not hold for the code backdoor. A trigger that has to be read from meaning is spread over several experts in the middle and late layers, yet a handful of top-ranked experts still matter where the same number of random ones do not.

Limits

Everything above comes from two backdoors, one routed model and one training run per setting, and the full comparison with the matched dense model covers only the token backdoor: the code backdoor was not planted in it. The monitor that reads neurons inside the reply, at the point where the code backdoor acts, was run on Qwen but not on the routed model. The two backdoors also differ in training: 3% poison for one epoch against 10% for three. Several differences between the models were not controlled.

The matched dense model needed 10% of training examples poisoned, where the routed model and Qwen took 3%, so its backdoor may be planted more strongly or more diffusely. That could explain part of why it is so expensive to edit. The tokenizers differ, so only ratios and percentage changes compare across models. Each model family was pretrained on its own data, and Qwen’s is not public. The matched dense model also starts from a higher loss (2.28 against 1.96). Beyond routing, the architectures differ too: the matched dense model normalises each block’s output after computing it (post-norm), while the routed model and Qwen normalise each block’s input (pre-norm), and Qwen is larger and uses a different attention mechanism in most layers. In the routed model the LoRA trained a separate correction for each expert, and the expert result may depend on that. LoRA dropout was 0 for the routed and matched dense models and 0.05 for Qwen. The main results use 200 prompts per set and the wider sweeps 64.

Two things are not known. The first is why the matched dense model is so expensive to edit at the neuron level. The cost comes from a few top-ranked late neurons rather than from ablating many: 723 random poles cost +0.5%, while the top 8 alone cost +5.5% on the 64-prompt runs. The leading guess is the post-norm design, in which changing one large late neuron rescales every other neuron’s write at that position, but it was not tested. The second is why the residual direction fails in the routed model. The routing explanation above fits, but directions fitted at other positions, or several directions at once, were not tried.
