Neuron browser

The 100 poles per marked model chosen for description (top 100 of the triggered − clean ranking, a choice fixed in advance), with their rank in every attribution ranking, detection scores, generic-corpus contexts with per-token shading, the upstream units that drive them where they were traced, and the firing clusters of the ten poles studied in the last experiment. A pole is one sign of one neuron's activation. Neuron descriptions written by an LLM are not published.

The interactive version loads when this section is on screen (needs JavaScript).

Ablation playground

Attack success rate (ASR, the share of greedy replies that contain the marker) and clean-loss cost against the number of units ablated, for both markers and every prompt set, with the baselines as toggles. Full-size checks and the upstream-driver ablation are drawn as diamonds.

Trace view: the token trigger from input to marker logit

The worked example from the technical report, one step at a time. The chain has a gap: nothing traced connects layer 6 to layer 27.

The interactive version loads when this section is on screen (needs JavaScript).

Sparsity

Loss increase when only a fraction of neurons per layer per token is kept, for top, random and bottom selections and both fill modes.

Monitors

ROC curves for neuron monitors and residual-stream baselines, and a threshold slider that counts alarms on each prompt set and on 500 generic-corpus windows.

Not built: "play the auditor"
